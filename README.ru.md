# MotionTimeControl

Управляйте временем жестом: разводите большой и указательный пальцы — видео идёт вперёд, сближайте — назад. Убираете руку — кадр замирает.

[English README](README.md) · [Лицензия MIT](LICENSE)

Проект работает локально на Python, OpenCV и MediaPipe. Камера обрабатывается в памяти, кадры не записываются и не отправляются на сервер. API-ключ не нужен.

## Установка

Нужен **Python 3.12**. Проверено с живой камерой на Apple Silicon / macOS 15+. Для Linux и Windows приведены команды запуска, но работа их камер вручную не проверялась. Нужна обычная графическая сессия — окно приложения не отображается на сервере без рабочего стола.

```sh
git clone https://github.com/satkan-satkan/MotionTimeControl.git
cd MotionTimeControl
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python setup_assets.py
python app.py
```

На macOS вместо ручных команд окружения можно запустить `./setup.command`, затем `./run.command`.

На Windows создайте окружение через `py -3.12 -m venv .venv`, активируйте `.venv\Scripts\Activate.ps1` в PowerShell. Если активация запрещена, вызывайте `.venv\Scripts\python.exe` напрямую.

На Ubuntu/Debian перед запуском модели установите системные графические библиотеки, необходимые MediaPipe даже для работы на CPU:

```sh
sudo apt-get update
sudo apt-get install -y libegl1 libgl1 libgles2
```

Установка скачивает официальную модель Google (около 8 МБ), проверяет её SHA-256 и создаёт собственные демонстрационные анимации цветка и ракеты. После установки интернет не нужен. Скачанные сторонние видео в репозиторий не включены; уже существующие локальные клипы не заменяются.

Для проверки без камеры и без скачивания модели:

```sh
python setup_assets.py --demo-only
python app.py --no-camera
```

## Управление

Покажите одну руку ладонью к камере. Сведите большой и указательный пальцы → **C**. Разведите на комфортную ширину → снова **C**. Держите ладонь примерно под тем же углом.

| Клавиша | Действие |
| --- | --- |
| **1 / 2** | Цветок / ракета; вкладки сверху также нажимаются мышью |
| **C** | Калибровка: закрыто → открыто |
| **X** | Сброс калибровки и удаление сохранённых настроек |
| **Space** | Заморозить / продолжить |
| **M** | Мышь / управление рукой |
| Перетаскивание таймлайна | Ручная перемотка |
| **H** | Чистое видео без интерфейса |
| **F** | Полный экран |
| **R** | Переподключить камеру |
| **Esc / Q** | Выход |

Буквенные клавиши работают в английской раскладке. При переключении клипов калибровка и положение жеста сохраняются.

После второго успешного нажатия **C** калибровка автоматически сохраняется в `.local/calibration.json` и загружается при следующем запуске. В файле только версия формата и две числовые границы жеста. Вся папка `.local/` исключена из Git. Начатая повторная калибровка не заменяет сохранённую, пока оба шага не завершены успешно. **X** возвращает стандартные значения и удаляет сохранённую калибровку. При заметном изменении положения руки или угла камеры откалибруйте управление заново.

Если файл повреждён или недоступен для чтения, приложение использует стандартные значения и показывает сообщение. При ошибке сохранения новая калибровка продолжает работать в текущем сеансе. Если удалить файл не удалось, приложение предупреждает, что прежние настройки остались на диске.

На macOS разрешите камеру приложению запуска, обычно Terminal: **Системные настройки → Конфиденциальность и безопасность → Камера**. После разрешения нажмите R или перезапустите приложение.

```sh
python app.py --clip rocket
python app.py --camera 1
python app.py --video "my-clip.mp4"
```

Последняя команда добавляет своё видео на клавишу **3**. Используйте короткие клипы с постоянной частотой кадров: до 30 секунд / 900 кадров. Приложение не воспроизводит звук.

## Настоящие видео вместо анимаций

Поместите свои подготовленные клипы в `assets/flower.mp4` и `assets/rocket.mp4` — они имеют приоритет над демо. В исходном прототипе использовались фрагменты **1:16–1:23** видео с цветком и **0:18–0:25** видео с ракетой. Ссылки на источники находятся в [THIRD_PARTY.md](THIRD_PARTY.md), команды обрезки через FFmpeg — в [English README](README.md#use-real-footage).

Используйте свои видео или материалы с разрешением на использование. Для произвольного сюжета удобнее `--video`: он будет подписан CUSTOM.

## Проверки

```sh
python -m unittest discover -s tests -v
python app.py --check
python app.py --snapshot previews/interface.png
python app.py --camera-check
```

Тесты создают собственные клипы и не обращаются к камере. `--check` запускает модель на пустых кадрах. Только `--camera-check` отдельно читает камеру 5 секунд, ничего не сохраняя. CI проверяет установку, генерацию демо и модель без камеры.

## Приватность

Приложение не отправляет кадры и не собирает телеметрию. Установщик обращается только к источникам зависимостей и модели. Видео, изображения, логи, `.env`, настройки редакторов, модель, виртуальные окружения и папка `.local/` с калибровкой исключены из Git. Перед публикацией логов всё равно проверяйте их: сообщения об ошибках могут содержать пути на вашем компьютере.
